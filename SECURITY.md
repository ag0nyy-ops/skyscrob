# Security

skyscrob stores other people's Apple Music and Last.fm tokens, so security reports matter.

Please report vulnerabilities privately via GitHub's **Security → Report a vulnerability** on
this repository, not in a public issue. Include steps to reproduce. You'll get a reply within a
few days.

In scope: token exposure, auth/session bypass, CSRF, injection, anything letting one user read
or affect another user's data, or anything that sends data anywhere other than Apple and Last.fm.
